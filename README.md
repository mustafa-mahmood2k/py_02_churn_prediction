# Customer Churn Prediction

Predicts whether a customer will churn based on age, gender, tenure, monthly
charges, and contract type. Includes a training notebook and a Streamlit app
for interactive predictions.

## Project structure

```
.
├── churn_pred_nb.ipynb  # EDA, preprocessing, model training & selection
├── app.py                           # Streamlit app for interactive predictions
├── scaler.pkl                       # fitted StandardScaler (generated by the notebook)
├── model.pkl                        # best trained model (generated by the notebook)
├── feature_columns.pkl              # exact feature column names/order the model expects
└── README.md
```

`scaler.pkl`, `model.pkl`, and `feature_columns.pkl` are all generated in the notebook

## Setup

```bash
pip install pandas numpy scikit-learn joblib streamlit
```

## Usage

### 1. Train the model

Open `churn_pred_nb.ipynb` and run all cells. This will:

- Load and clean the customer data (handling missing `InternetService` values)
- Encode `Gender` (binary) and `ContractType` (one-hot)
- Split the data into train/test sets (stratified, with a fixed random seed)
- Scale features with `StandardScaler`
- Train and tune five candidate models with `GridSearchCV`:
  Logistic Regression, KNN, SVC, Decision Tree, Random Forest
- Compare candidates by cross-validated accuracy and select the best one
- Evaluate the chosen model once on the held-out test set
- Save `scaler.pkl`, `model.pkl`, and `feature_columns.pkl`

### 2. Run the app

Once the notebook has produced the three `.pkl` files in the same directory
as `app.py`:

```bash
streamlit run app.py
```

Enter a customer's age, gender, tenure, monthly charge, and contract type,
then press **Predict** to get a Churn / Not Churn prediction.

## Model details

- **Features:** `Age`, `Gender`, `Tenure`, `MonthlyCharges`, `ContractType`
  (one-hot encoded)
- **Target:** `Churn` (Yes/No → 1/0)
- **Preprocessing:** missing `InternetService` values filled with `"None"`;
  numeric features standardised with `StandardScaler` fit on the training
  set only
- **Model selection:** candidates are compared on cross-validated accuracy
- **Evaluation:** accuracy plus a full precision/recall/F1 breakdown per
  class, since churn is an imbalanced problem — recall on the "Churn"
  class is the more business-relevant number

## Notes

- If you retrain with a different feature set, no changes are needed in
  `app.py` as it reads column names/order from `feature_columns.pkl`.
- The `ContractType` values assumed in `app.py`'s dropdown are
  `"Month-to-month"`, `"One year"`, `"Two year"`. If using
  different labels, update the dropdown options in `app.py` to match.
